# 数据与方法来源

本文件仅记录研究实验的数据和方法，不作为履历或业务指标证据。TextGuard、CiteRAG与NoveltyLab为AI辅助学习实现；基线和接口不重复计为新项目。

## 数据来源

- SMS Spam Collection：https://archive.ics.uci.edu/dataset/228/sms+spam+collection
- Wine：https://archive.ics.uci.edu/dataset/109/wine

## 方法来源

- 模型评价指标：https://scikit-learn.org/stable/modules/model_evaluation.html
- Novelty / Outlier：https://scikit-learn.org/stable/modules/outlier_detection.html

SMS页面规模可能与实际下载文件不一致，报告采用真实解析行数。原文可能含个人细节，仅私有缓存，不公开复制；词表与结果不包含原短信或电话号码。Wine用于受控类别迁移，不宣称真实异常标签。CiteRAG共享FlowBench自建知识片段，作者选择偏差明确披露。

论文、数据、代码和实测证据是研究的方法依据，不等于真实业务项目的证明。
