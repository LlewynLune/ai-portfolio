# 把 AI 辅助作品变成真正掌握的作品

下面是待执行学习任务，不是已完成履历。不要虚构完成日期或个人贡献。

## 1. TextGuard：一次可以解释的实验

- 独立重训，找到训练/验证/测试分集代码，解释为什么先去重。
- 只在训练/验证范围比较 C=1 与 C=4；测试不能重复调阈值。
- 解释 NB 高精度低召回与 Logistic 较多误报的取舍；不能只讲F1。
- 亲自修改归一化或词项统计，补单元测试，记录变化和复核。

## 2. CiteRAG：失败不是删掉就没有

- 对一条困难改写问题手算/观察 BM25 和 char 的排名。
- 为无答案问题增加说明，但新样本只能作为新集合，不能偷偷替换旧失败。
- 大模型配置后才做一次冻结的真实回答测试；保留返回usage、失败和人评支持性。
- 不发送内部/私人内容给未知provider；学习如何降低提示注入风险而非声称彻底解决。

## 3. NoveltyLab：正确解释分数

- 解释标准化只fit正常训练与fit全部数据的差异。
- 比较不同正常验证分位数，但不要用未知测试分数选阈值。
- 把“类别迁移”和“实际故障”区别讲清楚；解释正常测试12个限制。
- 独立画一张分数分布图并解释一个漏检，而不是把高AUC贴上去结束。

## 4. FlowBench：负责一个小改动

- 独立跟一条失败事件链，解释超时、预算、重试与幂等不是同一概念。
- 改一个明确参数，保存完整配置与运行证据。
- 仔细区分本地重复提交防护与远程 exactly-once。

## 可以真实写的贡献记录模板

日期：待填。问题：待填。本人修改：待填。测试/数据：待填。失败与取舍：待填。AI/开源协助：待填。证据commit：待填。

只有亲自做过并能解释的部分才填“本人”；AI 辅助生成的代码可作为学习资产，不应包装为过往工作经历。
