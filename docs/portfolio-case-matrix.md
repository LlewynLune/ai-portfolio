## 五类常见载体

1. **个人主页/个人网站**：承担第一入口，通常包含身份、研究兴趣、News、经历和精选成果。
2. **论文或技术报告**：承担问题、方法、实验和结论证据；技术报告不能自动等同于同行评审论文。
3. **代码仓库**：承担可复现证据，需要 README、依赖、数据、运行方式和结果说明。
4. **项目主页**：适合展示视觉结果、样例、模型入口、论文和代码。
5. **在线 Demo/模型页**：让人直接体验，但仍需说明输入范围、失败边界和数据条件。

## 对你的直接启发

- 你目前没有真实项目，先做一个“可运行、可解释、可复核”的旗舰项目，比填满三类目录更重要。
- 首页不要声称同时精通产品、算法和工程；应围绕同一问题，分别展示产品判断、实验设计和工程实现。
- 每个项目都要标明个人贡献、团队贡献、开源依赖和 AI 辅助部分。
- 没有测量结果时不写提升数字；原型、模拟、复现和上线必须分开。
- 仓库只保留公开链接，不复制内部材料、截图、代码或数据。
