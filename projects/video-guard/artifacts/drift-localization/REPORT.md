# 因果音画漂移定位：实测报告

## 判断：定位更有信息，但检测仍有延迟与漏检

旧模型冻结，新增结构性变化点真值与因果尾随窗。不能只报“发现漂移”：同时报告漏检、误报、定位误差与发警报延迟。本轮为自建RGB/PCM，未做真实数据泛化。

## 固定协议与参数选择

validation F1 subject to stable false alarm <=10%; fixed tie break; untouched test seeds; causal trailing windows size32/stride4; event tolerance800ms

验证160个；十组各120测试；三次独立重复各200。窗口32帧/步进4帧；模型/温度不重训。

|方法|置信门限|最小变化帧|确认次数|
|---|---:|---:|---:|
|raw|0.5|1|3|
|onset|0.7|1|3|
|mlp|0.9|1|3|

相关性置信与softmax概率不是同一含义；门限在相同验证集独立选择，不按测试调。
