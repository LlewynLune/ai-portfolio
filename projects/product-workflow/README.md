# 产品与工作流｜待填项目模板

状态：待填。尚未形成可展示的本人项目或验证结果。

## 一句话问题

待补：谁在什么场景中做什么事，具体卡在哪里。

## 用户与价值假设

待补：用户、任务频率、现行流程、痛点证据、需要验证的假设。没有访谈就明确写没有访谈。

## 范围与非目标

待补：一期只做什么、不做什么。解释为什么不单纯用规则或人工，以及哪些部分不需要 AI。

## 我的贡献

待补：独立完成、共同完成、使用现成组件、AI 辅助部分分别说明。团队成果不能写成个人独立成果。

## 人机分工

- AI：候选建议、语义理解、线索组织，待按项目填写。
- 确定性系统：计算、状态、权限、版本与校验，待按项目填写。
- 人：最终专业判断、关键确认与例外处理，待按项目填写。

## 两条可演示路径

1. 正常路径：输入 → 处理 → 引用证据 → 复核 → 完成，逐步补齐责任人、输出与状态。
2. 异常路径：材料缺失/规则冲突 → 停止结论 → 请求补证 → 人工复核 → 重跑，待按项目展开。
