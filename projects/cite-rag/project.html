Introduction

模型能写下一条记忆，不意味着这条记忆仍然正确。CiteRAG 从引用优先检索深化到来源支持的跨任务记忆：记录修订与撤销，回放原文检查笔记，在有限上下文中保留冲突证据，并让真实本地大模型输出可验证的结构化结论。

本作品关注产品与工程判断，而非堆叠功能：独立校验、传统强基线、预算消融、失败留痕与可复现运行。所有数据都是自建虚构软件设置，不使用公司材料。

来源事件 → 不可变ID与namespace → 模型notes → 原文支持 / 修订 / 撤销 / 冲突检查 → token预算下证据装入 → 本地模型生成 → 输出契约与全源校验 → 答案或拒答。

来源回放重建是确定性抽取，不冒充LLM自主学习。当前SQLite验证持久化和隔离，不等于多租户鉴权或恶意攻击防护。

Method

主实验在推断前冻结78条源记录和48个问题，16开发、32留出；比较原始上下文、来源检索、模型笔记与来源回放四策略。每次生成记录Prompt hash、模型版本、真实token、GPU峰值、原始文本与校验结果。

后续污染挑战和预算实验分别保存。小预算暴露v1冲突漏洞后，v2加入全源冲突检查、证据原子分组和整数类型适配；它是探索性修复回归，不是新的独立留出。

Limitations & Reproducibility

一次4bit本地模型运行、共享模板自建数据。521实际模型调用含512问答、6次整理和3次预热；重复策略、挑战和回归不是521个独立样本。没有自然语言NLI、权重记忆、RL、多日自主任务、真人评测、真实电气规范或线上收益。

实验由AI辅助实现，不包装为本人既往独立研发、论文或公司项目。内部检索只作选题参考，公开代码、Prompt和数据不含内部内容。

历史证据保持冻结

早期检索与内容去重报告仍保留：clean。旧报告llm_used=false没有改写，新真实LLM结果单独存放。
