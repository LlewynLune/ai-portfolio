# CiteRAG：真实本地大模型记忆工程实验

## 核心判断

不要把“模型写下的记忆”自动当作事实。本实验以来源回放、版本管理、显式拒答与输出契约检查来控制错误，但原始整理记忆与回放策略在主实验中同分。受控污染测试支持回放修复机制，不支持通用 Agent 能力、长期自主学习或生产效果结论。

实际本地模型调用 521 次：主实验192问答＋6整理＋1预热；挑战32＋预算消融192＋1预热；v2独立保存96问答＋1预热。48个问题模板实例，其中32留出；512问答轨迹不是512个独立问题。公开4bit权重，离线推断，没有付费API。

### 必须报告的强基线

不调用模型、直接解析当前Setting记录的确定性基线通过 32/32。此有限规则任务可被传统代码完全解决；LLM不是必要条件。本作品验证上下文与生成契约，不主张模型优于规则。

## 污染记忆挑战：探索性测试

主实验结束后预先声明四种干预：旧版本、跨namespace、错误值与缺失证据。只改模型记忆，不改原始sources或答案标签。每种在4个留出namespace各1题，16配对 × 2策略 = 32真实生成。

|策略|通过/分母|解析失败|校验失败|
|---|---:|---:|---:|
|unverified_notes|0/16|0|12|
|source_replay|16/16|0|0|

回放策略读取完整当前源记录，未校验策略只能依赖污染后的notes，信息可得性不同。这正是来源保留的产品价值，也意味着该对照不能证明LLM自身学会纠错。

## 工程验收与适用边界

- SQLite源ID不可变、幂等写入；notes按namespace独立替换，保存来源hash和原文引用；关闭后重开逐项验证。
- 追加hash链检查审计记录完整性；不是签名、访问鉴权或防恶意数据库篡改保证。
- 生成温度0、最大200输出tokens；整理最大1024；单次Prompt上限8192。未使用隐藏重试或自动选最优结果。
- 严格JSON解析、引用可见性、当前版本、撤销、冲突、精确单位、整数和双证据校验。有限Setting语法不是通用NLI。
- 模型整理与来源重建分开记录；旧artifacts的llm_used=false保留，只有新真实调用为true。

## 不成立的宣传说法

不是Anthropic、Seed或Kimi旗舰复刻；没有原创论文、模型预训练、RL后训练、权重记忆、数日自主Agent运行、真人测试、线上业务收益或保密审计。合成规则不是实际电气规范。当前验收重点是可追溯来源、真实本地生成、受控消融与失败分析。
