01 / TEXTGUARD · TRAINED MODEL

可解释文本分类
从训练到留出评测

真实训练 · 无密钥模型 Demo

TF-IDF＋Logistic，比较多数类和朴素贝叶斯；去重后隔离训练、验证与测试，导出权重在浏览器直接推断。

  • 固定留出测试，阈值仅验证选择
  • 误判哈希与导出一致性核验
  • 旧英文短信，不是现代诈骗系统
运行模型 → · 代码与方法 · 实测
02 / CITERAG · EVIDENCE-FIRST QA

引用优先问答
检索、摘录与拒答

本地实测 · LLM 接口未调用

BM25、字符余弦与RRF，困难问题和无答案问题单列；引用ID核验不替代语义支持复核。

  • 15篇自建说明、25个问题
  • 共享 FlowBench 语料如实披露
  • 真实 HTTPS 接口另需密钥及费用配置
检索与摘录 → · 代码与方法 · 实测
03 / NOVELTYLAB · NUMERICAL ML

多变量新颖性
模型对照与解释

实际拟合 · 13维输入 Demo

比较距离、Isolation Forest、One-Class SVM；只在正常训练拟合，在正常验证选阈值。

  • 178行公开数值样本
  • 预先固定默认模型，不按测试挑选
  • 类别迁移不是工业故障标签
计算分布偏离 → · 代码与方法 · 实测
04 / AI ALGORITHM · VISIONCAL

神经网络校准
与分布迁移鲁棒性

真实小型网络 · 公共图像

64→48→10 MLP与线性基线、温度缩放、噪声和平移对照；校准未必提升测试表现，保留高置信错例。

  • 参数实时推断与可编辑8×8像素
  • NLL/ECE/覆盖率与错误率分别报告
  • 不是MNIST、CNN或大型视觉模型
编辑像素运行 → · 原理 · 实测
05 / ELECTRONICS · CIRCUITID

电子电路辨识
学习回归与物理基线

RC数学仿真 · 四类分组

由32点噪声阶跃估计时间常数，对照阈值规则、曲线拟合、Ridge与MLP，检验偏置与范围外失败。

  • 独立训练/验证与3个测试seed
  • 真实参数推断和波形重建
  • 仅辨识RC乘积，非实测电路验收
输入波形运行 → · 原理 · 实测
06 / COMMUNICATIONS · CHANNELEST

学习型信道估计
导频、均衡与误码

理想频域仿真 · 先验对照

数据驱动线性估计、周期插值、先验LMMSE与真CSI oracle；同帧噪声对照NMSE和BER。

  • 32子载波、8导频、QPSK数据
  • 3个SNR、长delay OOD、3seed
  • 非射频实测，未实现同步/编码
运行复信道预测 → · 原理 · 实测
07 / AI DATA CENTER · POWERSCOPE

数据中心功率预测
时间因果与漂移

合成时序 · 离线只读

IT/冷却/损耗透明假设，下一5分钟预测与计划特征消融；保留突变误差和冷却漂移失败。

  • 时间留出，不读取未来遥测
  • MAE/RMSE与峰值标记分别验证
  • 非真实机房数据，不控制电气设备
运行负荷预测 → · 原理 · 实测
08 / TRANSFORMER · TINYATTENTION

从零因果注意力
训练、消融与迁移

CPU真实训练 · 合成查找

单块多头注意力、mask、layernorm与残差，基线消融、长度OOD和逐样本概率。保留未学会可靠绑定的失败。

  • 原生参数推断与attention轨迹
  • 训练/验证/测试前缀去重隔离
  • 微型机制，不是自然语言预训练
运行注意力 → · 公式与方法 · 实测
09 / PEFT · LORA-LAB

低秩适配
参数效率与遗忘

真实A/B更新 · 基座冻结

在共享小型基座上训练rank1/4，对照全量微调，验证选rank，记录旧任务保留与长度迁移。

  • 冻结断言、合并推断一致性
  • adapter原参数与训练日志
  • 低参数量不外推显存/节能收益
运行适配模型 → · 公式与方法 · 实测
10 / PREFERENCE · DPO-LAB

偏好优化
赢率不等于准确率

真实DPO损失 · frozen reference

beta对照与SFT，chosen/rejected排序、top1、KL与原任务保留分别测量。不把规则偏好称为真人对齐。

  • 梯度方向与log2起点测试
  • 冻结基座与共享数据边界披露
  • 偏好改进也可能产生严重漂移
检查偏好输出 → · 公式与方法 · 实测
11 / SPARSE COMPUTE · MOE-LAB

稀疏专家路由
负载与dense对照

实际top1分发 · 4专家

只计算所选expert，辅助负载平衡、偏斜分布与路由entropy。小型MoE不一定优于dense。

  • hook核验真实稀疏执行
  • active-like与total-like双基线
  • 非Transformer或分布式MoE
检查专家选择 → · 公式与方法 · 实测
12 / INFERENCE · SPECDECODE

精确路径与真实开销

  • k2/k4、3重复、逐prompt计时
  • 原生双模型实时验证轨迹
  • 非随机采样算法或GPU加速结论
